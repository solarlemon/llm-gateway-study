# 网络与调度验收记录

日期：2026-10-29。功能验证记录，不作为性能基准。

最终验收：Debug 构建通过，16 组集成场景通过，真实模型非流式、SSE 与断连后恢复通过。原始结果快照在 `docs/evidence-20261029/`；可重新运行测试生成新的 build 结果。

## 当前可以承担的实现范围

- **网络通信与资源管理：**基于 cpp-httplib 实现 C++ HTTP 网关，提供参数校验、非流式和 SSE 转发；通过共享所有权与 RAII 管理上游客户端、任务和执行配额，处理下游断连、上游异常与响应中断。
- **并发调度与过载保护：**实现独立转发 worker、有界 FIFO 等待队列、最大并发和排队截止时间；队列满返回 503，过期任务不进入后端，并支持执行截止时间和退出时取消。

用于个人简历前，还需学习代码并能闭卷解释。不能扩展成自研 epoll、无阻塞服务或未经测量的高并发/性能提升。

## 测试证据

- `tests/integration.py`：可控 mock，按队列状态和后端到达记录驱动测试。
- `tests/real_model_smoke.py`：真实 GPU 模型，验证非流式、SSE 和关闭客户端后配额恢复。
- 原始结果：`build/integration-results.json`、`build/real-model-results.json`。
- 后端证据：`build/real-model-server.log`，包含模型加载、取消和 slot 释放。

| 场景 | 验证 |
| --- | --- |
| 请求校验和上游状态 | 400/200/429 与返回体 |
| FIFO 和队列容量 | 单运行槽被屏障占用，逐个排队、释放，核对后端到达顺序；超额 503 |
| 排队过期 | 等待请求 504，后端没有收到 |
| 两个执行槽、零等待 | 两个任务同时执行，第三个 503 |
| 上游失败 | 连接失败、正文截断、响应体过大，配额恢复 |
| SSE | 分次发送、任意字节切分、UTF-8、完成标记和增量到达 |
| 流式异常 | 截断、正常 EOF 却缺少结束标记、错误内容类型 |
| 断连 | 排队、非流式执行、持续流式、静默流式 |
| 慢客户端 | 不读取响应，写超时取消；应用 FIFO 峰值不超配置 |
| 总截止时间 | 上游没有返回响应头时仍能超时并中断 |
| 退出 | 运行和等待任务同时存在时正常 SIGTERM 退出 |

首次真实验证：非流式 HTTP 200，prompt 35 token、生成 11 token；SSE 12 个 data 帧含 `[DONE]`；结束时 active/queued 为 0。数字仅描述该次 smoke，不是稳定性能指标；最终实测以结果 JSON 为准。

最终复测：非流式 HTTP 200、输入 35 token、输出 8 token，SSE 22 个 data 帧且含结束标记。生成采用后端默认采样，内容/长度可变。模型加载前后 GPU 使用量约 1582/2144 MiB；详细后端日志确认 CUDA0 KV 缓冲为 24 MiB、计算缓冲约 36.51 MiB。以上是该次功能验证观测，不作为资源优化收益。

本机后端日志出现 `cancel task` 与 `stop processing`，说明该次断连引发后端取消与释放。不能推广成任意后端立即停止 GPU。

现有 llama.cpp 为 ZIP 目录，不存在可读 Git commit。真实测试 JSON 保存 HTTP/JSON 依赖 SHA256。模型 SHA256：`74a4da8c9fdbcd15bd1f6d01d621410d31c6fc00986f5eb687824e7b93d7a9db`。

## 实现边界

HTTP 与上游是有界线程的阻塞 I/O；显式队列之外还有有限框架队列、库和内核缓冲。SSE 已发出后不能修改 HTTP 状态。FIFO 保证网关调度顺序。吞吐、Prefill/Decode 和 KV Cache 对照实验尚待开展。
